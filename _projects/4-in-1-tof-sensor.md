Compact 4-in-1 Time-of-Flight sensor board.

Custom PCB carrying four ToF sensor breakouts (TOF1–TOF4) behind a shared I2C bus (SDA/SCL), with dedicated XSHUT lines gated through 74HC32/SN74HC08 logic so each sensor can be addressed individually, plus a BNO055 IMU header on the same board.
